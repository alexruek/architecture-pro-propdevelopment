# Task 1 — Mindmap безопасности данных

## Описание

Mindmap классифицирует данные компании PropDevelopment по стандартам ISO/IEC 27001/27002,
определяет актуальные риски для каждой категории и дает их оценку.

## Файл

`mindmap.drawio` — откройте в [draw.io](https://app.diagrams.net)

## Классификация данных


| Категория               | Примеры данных                                                                                                |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Публичные               | Каталог объектов, информация о плановых работах ЖКХ                            |
| Внутренние             | BI-аналитика, конфиги систем, API-ключи партнеров, данные сотрудников |
| Конфиденциальные | ПДн клиентов, данные онлайн-сделок, платежные данные ЖКУ                    |
| Секретные               | Биометрия, данные СМЭВ/гос. органов, финансовая отчетность                |

## Логика классификации

- **Публичные** — данные, которые компания намеренно публикует для клиентов и собственников.
- **Внутренние** — данные для операционной деятельности, не предназначенные для внешних пользователей.
- **Конфиденциальные** — персональные и финансовые данные клиентов, доступ к которым ограничен и регулируется 152-ФЗ.
- **Секретные** — данные с максимальным уровнем защиты: биометрия (спецкатегория ПДн),
  данные государственных интеграций и финансовая отчётность компании.

## Шкала оценки рисков


| Уровень                  | Критерий                                                                                       |
| ------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 🟡 Незначительный | Прямого ущерба нет, бизнес продолжает работу                     |
| 🟠 Значительный     | Финансовые или репутационные потери, требуется реакция |
| 🔴 Критический       | Правовые последствия (152-ФЗ, УК РФ), угроза бизнесу             |

## Ключевые находки

- Инцидент уже происходит: клиент видит данные другого клиента в личном кабинете —
  **искажение конфиденциальных данных, оценка: критический**.
- API партнеров (управляющих компаний) работают без единых политик безопасности —
  партнер одной УК может читать и изменять данные клиентов другой УК.
- Биометрические данные (умный домофон, шлагбаум) относятся к специальной категории ПДн —
  требуют отдельного регулирования и явного согласия субъекта.
